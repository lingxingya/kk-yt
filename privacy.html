Privacy Policy

Last updated: November 1, 2026

This Privacy Policy describes how the Douyin to YouTube Pipeline ("the App", "we", "us") handles information. The App is a personal, single-user automation tool operated by an individual developer.

1. What the App is

The App is a private tool used by its owner to transfer short-form videos the owner has the right to use from Douyin to the owner's own YouTube channel. It is not a public service and has no end users other than its owner.

2. Google user data we access

The App uses Google OAuth 2.0 and requests exactly one scope:

ScopeWhy it is needed
https://www.googleapis.com/auth/youtube.upload To upload video files to the owner's own YouTube channel via the YouTube Data API v3.

The App does not request or access:

  • Gmail, Google Drive, Google Calendar, or Google Contacts
  • YouTube watch history, subscriptions, playlists, or private analytics
  • Any other Google account data

3. How we use Google user data

Google user data (the OAuth token and the ability to upload to the owner's channel) is used solely to perform the upload operation the owner explicitly initiates. We do not use Google user data for advertising, profiling, analytics, or any secondary purpose.

4. Storage and retention

  • OAuth refresh token: stored locally in a file on the owner's own server, protected by filesystem permissions. Never transmitted to any third party.
  • Video files: downloaded to a temporary directory on the owner's server, then deleted immediately after the upload completes, whether the upload succeeded or failed.
  • Video metadata (title, duration, quality tiers) is held in memory only for the duration of a single job and is not persisted.

5. Sharing and disclosure

We do not sell, rent, trade, or otherwise share Google user data with any third party. No data is shared with advertisers, data brokers, or analytics providers.

The App does send video identifiers to TikHub, a third-party API service, solely to resolve a public Douyin video link into a downloadable file URL. No Google user data is ever sent to TikHub.

6. Data deletion

The owner can revoke the App's access at any time at https://myaccount.google.com/permissions. Revoking access invalidates the stored OAuth token immediately.

To request deletion of any data associated with this App, contact the address below. Because the App stores no server-side user database, deletion consists of removing the local token file and any temporary video files — which the App already does automatically.

7. Security

The App runs on a private server owned by the operator. Credentials are stored in files readable only by the operator's OS user account. All network communication with Google APIs uses HTTPS.

8. Children's privacy

The App is not directed to children under 13 and does not knowingly collect any information from children.

9. Changes to this policy

Any changes will be posted on this page with an updated "Last updated" date.
